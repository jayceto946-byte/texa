# Learning canvas

The main answer area is a readable learning document. Keep the question, answer, formulas, sources, and composer aligned on a clear content axis while allowing tables and display formulas to overflow safely.

Use distinct headings, body, emphasis, and secondary text. Preserve selection and copying. Explanations may be concise; worked examples and derivations may need complete steps.

Citations and concept links should make provenance inspectable. Show supporting detail in an inspector or local disclosure when useful, without interrupting reading. Attachments, task gates, and repair states remain visible when they affect the answer.

Check representative long Chinese content with headings, formulas, a table, and citations at narrow and wide desktop sizes. Keep the composer usable as the content width changes.

For composer work, keep attachment/context, editable question and tool/submit rows distinguishable. Bound long input with internal scrolling so the submit or stop action remains reachable. Reuse the current working behavior before changing sizing mechanisms.

Use the existing workspace roles as the comparison baseline: reading text 16px/1.9 at a 740px column, interface 13px, support 12px and metadata 11px; desktop nested controls 28px and send 30px. These are current role values, not universal sizes: mathematical tables, touch targets and narrow layouts may need different space. Inspect effective styles because StudyDesk and page rules can override shared roles.

When adding a panel inside the reading flow, inspect cumulative padding rather than adding another card by default. Keep question, answer, sources and composer on their established axis; adjust spacing to show grouping, without copying another product's radii or gray scale. These applications were checked in [the Composer source study](../../../../docs/design/claude-ui-source-study-2026-10-19.md); that study did not approve a new page composition.
