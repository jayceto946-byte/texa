# Product objects

Texa organizes study around a learning scope, source material, a session, questions, answers, concepts, exercises, mistakes, and review items. These are user concepts, not backend fields.

- Scope and session provide orientation without repeating the same selector or title everywhere.
- Textbooks and cited sources carry provenance. A source reference should lead to inspectable detail; model output alone is not a source.
- Questions may contain text, formulas, or attachments. Answers can be explanation, derivation, summary, or solution in a readable document flow.
- Concepts connect related learning; exercises and mistakes support practice, attribution, and later review.
- Review items should expose the next useful action. Progress detail belongs where it changes that action.

Use short, specific Chinese copy. Surface a model or technical detail when it changes the user's decision.

## Scene responsibilities

- Learning: ask, read, inspect evidence, continue a session.
- Library: manage learning material and import it.
- Review: capture and revisit mistakes and due concepts.
- Exercises: browse source-backed problems and practice.
- Settings: configure runtime, models, backup, version, and repair.

Keep the main task visible. Add a route or region when the task needs it, rather than to match an object list.
