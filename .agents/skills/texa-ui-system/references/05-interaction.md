# Interaction

## Principles

- Controls are contextual, keyboard-first, and low in visual weight.
- Keep common actions visible; move low-frequency actions into a More menu, attachment menu, or inspector.
- Frequency of use drives placement, not visual weight.

## Keyboard and focus

- Preserve visible focus for every interactive element.
- Support Escape to close menus, dialogs, drawers, and inspector.
- Keep tab order consistent with visual order.
- Never rely on hover alone.
- Use semantic button, link, input, and heading elements.

## Motion

- Short transitions for panel, menu, collapse, focus, and small state changes.
- 90–180ms duration.
- Respect reduced motion.
- Animate transform or opacity only when useful.
- Prohibited: page entrances, flying cards, gradient animation, bounce, decorative shimmer, perpetual motion.

## Progressive disclosure

- Hide source detail, concept detail, metadata, advanced settings, archived items, and long technical logs.
- Never hide current scope, active repair, or the primary action.
