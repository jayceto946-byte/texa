# Typography

## Families

- Application UI: `Segoe UI Variable`, `Segoe UI`, `Microsoft YaHei UI`, `Microsoft YaHei`, system sans-serif.
- Mathematics: `STIX Two Math`, `Cambria Math`, `Times New Roman`, serif.
- Monospace: JetBrains Mono or Cascadia Code for code, paths, hashes, and stable technical values.
- Learning notes: LXGW WenKai Screen only for explicit note or manuscript semantics, never general UI chrome.

## Scale

- Display, rare: 30px / 1.24 / 600
- Page title: 20px / 1.3 / 600
- Section title: 16px / 1.4 / 600
- Body: 14px / 1.62 / 400
- Control: 14px / 1.4 / 500
- Small: 12px / 1.5 / 400 or 500
- Caption, rare: 11px / 1.4 / 400

Most application screens should use page title, section title, body, and small only. Avoid 700 weight except rare emphasis inside learning content.

## Reading content

- Keep answer measure near 72ch for Chinese and mixed math text.
- Use 1.6 to 1.72 line height for body explanations.
- Keep Markdown headings restrained and proportionate to the answer.
- Allow text selection and copying.
- Give tables and display formulas horizontal overflow.
- Keep inline formula baseline aligned with Chinese body text.

## Hierarchy

Use weight, spacing, and muted color before increasing size. Do not use uppercase tracking as decorative hierarchy. Do not label ordinary answers as `AI Assistant`; use `回答` only when a role label is required.
