# Spacing

## Tokens

Use a 4px base scale: 4, 8, 12, 16, 20, 24, and 32px. Allow 40 and 48px only for large reading boundaries or empty-state breathing room. Avoid one-off spacing values such as 13, 17, 19, and 27px.

## Density

Dense does not mean cramped. Use 32 to 40px rows for frequent controls, 40 to 48px for primary inputs, and 8 to 16px internal gaps. Use whitespace for grouping before adding a surface.

## Widths

- Sidebar expanded: 272 to 304px.
- Collapsed navigation: 52 to 60px.
- Inspector: 320 to 400px, never below 300px.
- Reading column: 720 to 880px depending on math and tables.
- Utility pages: 1120 to 1280px, while true split views may use available width.

## Resize behavior

- At 720px minimum window width, keep the primary action usable and the composer visible.
- Below about 920px, use drawer navigation and overlay inspector.
- At normal laptop widths, avoid three permanently visible columns.
- At wide widths, add useful context, not empty margins.

Do not optimize for phone-first layouts in this desktop product. Preserve basic compact behavior for narrow windows.
