# Anti AI slop

Treat these patterns as disabled by default:

- large hero
- gradient heading
- purple gradient
- glassmorphism
- blur everywhere
- excessive shadow
- huge radius
- pill everything
- card everything
- nested cards
- sparkle icons
- fake AI status
- decorative badges
- marketing copy
- random illustration
- KPI dashboard
- huge empty whitespace
- excessive bold
- five or more text sizes on one surface
- unnecessary animation
- decorative loading
- rainbow status colors
- feature-card landing-page layout

Also reject Welcome back or AI Powered workspace copy, decorative icon squares on every row, oversized headings, quick-action card grids, concept tag clouds, citation card piles, nested bordered surfaces, equivalent primary buttons, and generic analytics for non-actionable progress.

## Exception rule

Use a disabled pattern only when it has a functional reason that cannot be expressed more simply. Record the reason in the review. Looking polished is not a functional reason.

## Review result

Classify each original issue as REMOVED, REDUCED, or JUSTIFIED. Do not use `polish later` as a result.

## Mechanical review

- Count cards and nested bordered containers.
- Count radius values and text sizes.
- Search for gradient, blur, shadow, sparkle, pill, welcome, AI, magic, and marketing copy.
- Verify every badge and status color has semantic meaning.
- Verify every animation communicates feedback or state.
- Verify the main task remains the first visual anchor.
