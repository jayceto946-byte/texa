# Bundled fonts

The frontend self-hosts the following fonts for offline Electron use.

## JetBrains Mono

- Usage: code blocks, inline code, identifiers, and other monospaced content.
- Bundled subset: Latin, Regular 400.
- Source package: `@fontsource/jetbrains-mono`
- Upstream: https://github.com/JetBrains/JetBrainsMono
- License: SIL Open Font License 1.1
- Copyright: Copyright 2020 The JetBrains Mono Project Authors.

## LXGW WenKai Screen

- Usage: learning suggestions and Markdown quotations only.
- Bundled form: Unicode-split WOFF2 webfont, Regular 400.
- Source package: `lxgw-wenkai-screen-web`
- Upstream: https://github.com/lxgw/LxgwWenKai-Screen
- Webfont packaging: https://github.com/CMBill/lxgw-wenkai-screen-web
- Font license: SIL Open Font License 1.1
- Webfont package license: MIT
- Copyright: Copyright 2021-2024 LXGW; Copyright 2020 The Klee Project Authors.

The common SIL Open Font License text is included in `OFL-1.1.txt`. The webfont packaging license is included in `MIT-Webfont-Packaging.txt`.
