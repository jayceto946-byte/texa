# 教材、习题的智能整理

正文来源统一进入 Canonical Document IR。教材目录的 AI 校对结合全书目录和正文标题更新目录草稿，并分批校正 OCR 文字。习题与教材例题候选中的 AI 校对会对照来源校正题干/公式/选项/子问、检查边界与附图、分章配对原书解答，并提取考试年份、出处和题型。模型不解题，不补写答案，不直接发布索引或写正式题库。

## 用户流程

- 文件习题可先选起始、结束物理页；范围在候选生成和模型调用前生效。留空处理全文。Word 没有稳定物理页，按全文处理；独立答案文件保留完整范围。
- 导入界面只有整理动作、进度及结果摘要。移除手工单价、请求数、token 上限和关联 PDF 常驻表单。候选页顶部只保留必要操作按钮，不展示处理日志/内部字段；左侧筛选固定，题目列表独立滚动，整理后候选数量即时更新。费用明细放在处理记录中；已有 PDF 自动作为视觉来源，只有 MinerU 包时使用已有文字、坐标和裁片。
- 目录整理不再只扫描前若干物理页。先核对全书标题及目录锚点，再处理正文。完成后替换旧本地草稿；若没有需调整的目录则明确显示。恢复识别目录会停用模型候选并回到保留的原始来源，回执仍保留。
- 修正后的教材继续现有确认导入/staged index 发布；习题生成新的不可变来源快照，继续候选校对与确认入库。模型结果不会覆盖原文件、现有活跃索引或用户学习记录。
- 教材例题/习题抽取会额外冻结所选范围内的完整原始来源，包含尚未切成候选的正文，而非仅保存已抽出的题目。候选页可直接发起 AI 校对；结果写入独立习题来源，例题范围仍只返回例题，不更改教材索引。新上传的 PDF 或 ZIP 中唯一的 PDF 自动留存为校对图像来源。
- 习题通过“编辑题目”直接修改渲染后的题干、答案、解析，点击公式使用可视化编辑；取消逐块原文对照和分界分配界面，原始Canonical来源仍在本地留存。可选解释放在问号帮助中，固定筛选项沿用文字标签和下划线，数字紧邻标签。
- 拆题按题干空行定位，必须明确原解和图表归属。原解可归其中一题或按答案/解析空行分别分配；图表可明确共用，组合子图不可拆散。子题保存独立来源区间及全组分配计划，允许分别入库；来源未对齐时保留编辑等待核对，不能复制整份来源确认。该可选计划保存于既有候选/回执 JSON，不迁移数据库。
- Word 习题导入按 OMML 结构转换公式，保留表格与内嵌位图。不支持的数学、OLE或矢量对象保留原XML并提示补充PDF，不展平成貌似完整的文字。旧Word来源需重新解析才能采用新结构。
- PDF/MinerU来源保留物理页覆盖，缺失页不会因没有候选而消失。有原PDF时，用户启动AI校对后逐缺失页转录、恢复图表并保留人工核对提示，共用既有预算/停止/请求回执；无法读出或没有原页时保留缺口。纯扫描文件零候选也能进入校对页。本能力用于独立习题来源，教材本体仍走原有导入发布流程，教材例题副本不扩大所选来源页。
- 点击智能整理先获取不调用模型的范围/费用估算，弹窗明确处理整批来源、候选数、物理页数、实际识图模型及可能计费，确认后才派发。运行时可继续浏览/编辑并停止后续请求；已发送请求可能仍计费。整理完成时若有并行手动修改，不自动覆盖，用户可保留编辑或明确采用整理结果。

## 模型与来源边界

复用设置中的识图角色与供应商中立模型工厂，本次请求关闭 thinking，不修改已保存的角色配置。DeepSeek 官方 `deepseek-flash` 及兼容别名支持文图输入。

目录阶段提供全书候选标题、目录原文、来源 ID 和真实物理页；有原页或相关裁片时附上。文字批次以约 9000 字符为目标，优先保留程序初判的完整题目，单组上限 24000 字符/8 个物理页（单个超长来源块保持完整）；额外提供相邻来源块及最近标题。起点只是建议，模型可纠正。每批同时提供可用原页及公式/图表裁片；不再只在附图归属阶段看图。超长题仍可能被上限分开，邻接上下文不能保证覆盖任意长度。

模型返回唯一原文片段的修正、角色和分界，不重写整章。修正保留原 OCR、修改原因及来源位置；数值变化必须由已实际提供原页/裁片的来源块支持，并明确声明 image 依据。无图数值修正或无法唯一对齐时保留原文并记录。AI 修改过正文的候选带人工核对提示，可展开修正前后对照；这不是数学正确性证明，也不会自动修正原书本身的数学错误。

年份、考试/院校/试卷出处、题型写入既有来源结构 JSON，随候选、入库记录及检索保留；无需数据库迁移。规则不再只识别 `#` 编排条中的年份；AI 属性提议必须附输入中可定位的文字片段，年份须能在片段中找到。讲义版本/文件名年份不视为考试年份。属性目前以只读来源信息展示，未实现独立的属性人工修订表单。

题目/答案分界先从共享来源投影恢复，再按章及完整题干一致性/唯一答案编号组织有界配对任务。常规模型请求最多30000字符，题干与原解完整提供；超长但来源逐项一致或同章唯一答案编号的关联由确定性规则处理，不截成摘要冒充模型已看全。附加原解和隐藏重复题干是两个操作，只有完整题干一致、已知出处/编排不冲突时可隐藏重复；保留符号、次序及ASCII词/数字之间有意义的分隔，数字集合不能证明题干相同。

支持题后跟解、题目区后接部分题解、各章反复出现题目/答案区及独立答案文件。不会在第一次“参考答案”后截掉后续章。测量数据行不作为小数题号；一个已确认题目起点的多行原文只建立一个题目，后续数据行仍归原题。纯答案按章内唯一题号匹配，未匹配来源ID继续留存；不同条件、歧义归属或仅题型相似的题分别保留。原书题号统一作为候选索引与来源字段，不按整本书任意重新编号。

跨题附图、解答图、手写批注及同页子图单独检查。图像阶段只允许修改图片归属，不能改变目录或习题区标题。结构提议必须引用已有来源；分段须完整覆盖原块。局部无效提议保留来源并记录，不作为整本 IR 损坏处理。通用数值条件检查拒绝把不同数值的题合成同一题。

## 费用、失败与恢复

单价由服务端费率目录估算，用户不在导入表单填写。目前 DeepSeek 官方 Flash 按 2026-11-01 核对的人民币费率及返回的缓存/非缓存输入、输出 token 计算；其他未知服务保留用量，不伪造价格。费用受请求预留和整理总预算限制，供应商实际账单为准。

调用前持久化请求状态，返回后保留实际用量、模型名、请求 ID、耗时和费用估算。响应丢失/失败不自动重发；用户明确点击重试时，只重试未完成部分，旧费用及未知用量预留仍保留。正文后续失败或达到预算时，已经接受的目录/文字修正仍形成部分候选，未处理内容保持原样。

文件整理保留原始审阅引用，新候选继续使用同一回执账本，避免候选 ID 更新后丢失结果摘要或重复付费。独立答案文字校正与题目共用费用预算。供应商异常正文和凭证不写入回执。

“结构审阅未完成”是旧的后台任务通用失败文案，不是题目判错或结构检查结论。当前记录分别显示模型连接、输出截断/格式、本地保存等原因或失败步骤，并保留未知用量。用户可在发送确认框中调整估算累计费用上限；已知价格时用于预算控制，实际计费以供应商为准。提示词/来源身份改变时保存旧账本副本，新版本会重新处理，不宣称跨版本复用全部已完成结果。

## 附图交付与兼容

图像入库后独立保存到 `PROGRESS_PATH/exercise_assets`，以题目拥有的资产接口读取；题干图与答案/解析图分别展示。已有 VisualProblemIR/回答链路用于附图解题，缺失条件继续要求补充，不生成平行答案链路。标准 progress 备份包含图像。

本次只扩展 Canonical attributes/source metadata 和既有文件快照字段，不迁移数据库表或改动活跃索引。新 Word/文字来源也保留 Canonical 来源；历史缺少完整来源的旧候选需要重新解析。模型修正并不等于人工金标或数学答案准确率证明。

## 受损来源与独立导出

未识别占位符和大段重复只作为复核信号，不直接删除内容。整理时提供相邻正文及现有公式裁片供模型复核；确认的批注排除，无法确认的片段隔离到context并标记source_ocr_damage，原始文字仍可回查。题干和解答不把受损源片段当作正常内容；独立导出列明尚未恢复的位置。

公式输出不依赖浏览器补齐定界符；表格单元格的相邻公式明确分隔，HTML合并格按行列跨度展开为Markdown。当前样本1380个数学片段在原始Markdown和应用预处理后均可被KaTeX解析，不等于OCR数字或数学答案正确。
