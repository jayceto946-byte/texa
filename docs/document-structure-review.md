# 教材与习题的视觉结构审阅

正文仍由来源适配器进入 Canonical Document IR。共享结构恢复提供初始目录、练习单元和来源位置；用户可在教材目录确认、已导入教材目录校正或文件习题候选校对中启动视觉辅助校正。模型负责提出来源块角色、标题层级、题干/解答边界、跨题图表归属与同页子图组合，程序负责检查来源引用、完整文本分段、物理页和发布流程。

## 输入与费用

- 复用设置中的独立识图角色和供应商中立的模型工厂，不修改用户保存的模型配置。结构审阅在本次请求关闭 thinking；支持 DeepSeek `deepseek-flash` 和兼容别名 `deepseek-v4-flash` 的文图输入。
- 默认选择目录、章界、图表、题目边界及覆盖抽查页，上限 24 页；也可选择逐页审阅并提高上限。界面显示本次页数、总页数和最大请求数。抽查没有覆盖的页面不代表已核实。
- 每批最多 2 个目标物理页，顺序执行。只发送目标页及必要邻页的来源块文字与坐标，每页最多 14000 字符；有原始 PDF 时渲染目标页，长边最多 1600 像素。已有来源裁片每批最多 24 张。被省略的文字、图像与覆盖范围进入回执。
- MinerU 包不一定含完整页面。没有原始 PDF 时明确显示“无完整原页”，只提供 OCR 坐标和已有裁片，不把它描述成原页视觉验证。用户可关联物理页数一致的原始 PDF；本地关联本身不调用模型。关联原页会更换审阅缓存身份。
- 开始前填写所用服务的输入/输出单价与费用预算。按文字 UTF-8 字节、模型目录的图片 token 预留值和每次最多 6000 输出 token 预留费用，预计超预算便停止派发。API 返回明确 token 用量时修正估算；这不是供应商账单硬上限。DeepSeek Flash 的图片预留为官方每图最多 1024 token，其他未知模型保守预留 16384。
- 不在导入时自动调用付费模型，不发送整本教材长文本。人工校对与本地规则恢复可独立使用。

## 修正与恢复

模型只选择已提供的来源 ID 和白名单角色，不能重写正文、提供文件路径、编造标题文字或补出正文缺失的章节。粗粒度 OCR 块可按原始 Unicode 字符区间分段，区间必须完整覆盖原块。原始文字、物理页、来源坐标及原始资产保留。

后台任务沿用 JobManager，逐批保存调用前状态、结果、已知用量和未解决项。相同来源版本、模型、选页及原页身份复用已有批次；失败或响应丢失不自动重发付费请求。停止不删除已完成批次。供应商异常正文不落入任务回执，以免保存凭证或请求 URL。缓存失效后的新请求会重新消耗用量。

教材结果保存在独立候选中，用户继续现有目录预览/确认，之后才通过 staged index 发布；不直接改 active 索引。文件习题生成新的不可变来源快照并重新投影候选，仍需用户校对后入库。模型给出的 uncertain/unknown、缺失输入和省略内容保留到回执，不等同于正确率证明。

## 习题附图

来源校对后的题干、答案、解析、上下文保留明确角色。必要图像必须有可读来源资产；图表归属未审阅时继续提示人工核对。入库时将所用图像复制到 `PROGRESS_PATH/exercise_assets`，在习题 `extra_fields.source_attachments` 记录归属；不迁移数据库表结构。读取接口按题目拥有的资产返回，正式阅读器按题干/参考内容展示，普通 progress 备份包含这些资产。

附图解题使用既有识图角色生成 VisualProblemIR，再进入既有回答生成链路；缺图、图像超出单次上限或必要视觉条件不明时要求补充。视觉解释存在不确定项时不能标为已核实。完整题干与附图可读性不等于数学答案准确率。
