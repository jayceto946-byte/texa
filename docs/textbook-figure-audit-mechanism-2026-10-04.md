# 教材图片审核机制与本轮验证

已把图片审核接入共用 Canonical 保存入口，并提供旧教材重审、批量重审、桌面问题列表和修复候选结构校验。审核不编辑图片、不调用模型、不重跑 OCR、不修改现有 IR 或索引。

之前的组合图是程序按原解析坐标排布原始裁片，并绘制 OCR 已有的子图标签和短标注。原始裁片没有修改；临时组合图会清理。它只能恢复展示关系，不能证明标签位置正确，也不能补回漏裁的原页像素。88 个组合候选生成成功不能表述为全书内容已审核通过。

## 使用

桌面开发版：**教材 → 对应教材的“更多教材操作” → 审核图片**。支持疑似问题、确定的结构错误、证据不足、全部四类筛选、分页、重新审核和查看原始裁片。预览使用原始裁片接口，不使用组合图接口。

新教材：所有调用 `persist_canonical_book` 的来源适配器自动生成同目录的 `figure_audit.json`；PDF、Word、OCR、MinerU 共用规则。没有图片记录或缺少 normalized 页内坐标时，报告如实披露适用范围。审核诊断不使仍可检索的正文失效。

旧教材批量重审，在项目根目录执行：

```sh
./venv310/bin/python scripts/audit_textbook_figures.py \
  --all \
  --progress-root '/Users/jichengqian/Library/Application Support/kaoyan-assistant-desktop/data/progress' \
  --vector-root '/Users/jichengqian/Library/Application Support/kaoyan-assistant-desktop/data/vector_db' \
  --output-dir /private/tmp/texa-figure-audit
```

可用 `--book '书名'` 替代 `--all`，重复 `--book` 可选择多本。每本独立输出 JSON，另有 `summary.json`；某本来源损坏或版本失配不掩盖其他书的结果。输出必须在教材和索引目录之外。文件只写到指定报告目录。

同一本、同一 Canonical 和规则版本，可通过 `--compare-with 旧报告路径` 输出新增、仍存在、规则不再检出的信号 ID。后者不等于人工接受或语义正确。Canonical 或规则版本变化会拒绝直接对比，避免旧结论套到新教材。

只读接口：`GET /api/books/{book_name}/figure-audit?category=suspect&offset=0&limit=20`，limit 范围 1–500。实时读取当前来源，避免直接展示过期落盘报告；正常桌面鉴权继续生效。完整修复提案保留在 CLI 报告中。

## 自动检查与判断边界

| 类别 | 检查 | 输出意义 |
|---|---|---|
| 确定的结构错误 | 重复身份、无效坐标/页码/来源、资产越界/缺失/哈希变化、组合越页或越章节 | 可以用程序验证的合同或文件错误；阻止修复候选安装 |
| 疑似问题 | 图题坐标与声明父裁片不匹配、正文混入图题、图题原文与 IR 不一致、多个图题归属歧义、组合图号冲突、相邻裁片未分组 | 有可追溯信号，需要核查；几何阈值可能误报 |
| 疑似问题 | 子图标签不连续、正文引用的子图标签未被图题 OCR 识别 | 标签可能在图片内，不能直接断言缺图或补造标签 |
| 证据不足 | 不具备页内坐标/源裁片/源哈希，或尚未比较完整原页 | 当前证据无法支持对应结论；不能当作通过 |

每条信号记录稳定 ID、规则、类别、物理页、来源 block ID 和证据坐标/文本。报告携带 Canonical hash、caption nodes hash 和规则版本。当前数学文本匹配只忽略空白；转义、公式排版等差异会保留待核查，数字或运算符差异不会静默消除。

归组规则现在排除“图 X 所示…”之类叙述正文作为公共图题锚点。规则采用本地结构与图号/子图标签模式，并非全语言、所有版式的识别器；当前几何阈值和误报率尚无跨书人工金标校准。

修复候选脚本 `scripts/repair_textbook_figure_layout.py` 在安装前增加独立审核和结构验收：原始裁片全部保留且在目录中恰好覆盖一次、成员身份有效、分组投影一致、页码/章节边界有效、审核版本一致。结果分开记录 `structural_status` 和始终未被此检查证明的 `quality_status=unverified`。结构失败拒绝安装；疑似信号不会因生成组合图成功而关闭。默认只生成报告，`--install` 仍只安装可回退的派生关联文件。

新报告随候选教材发布，候选失败时恢复旧报告。报告作为可重算诊断，不进入不可变 IR 快照的内容身份；从历史 IR 回退后，桌面接口可重新计算，避免规则升级导致同一个 IR hash 的快照内容冲突。没有数据库、依赖、Canonical schema 或索引格式迁移。

## 《传感器原理及应用》实测

使用真实数据只读运行 `--all`；当前根目录只有这一本具有 Canonical IR 的教材，未把多来源合成测试称为多本真实书验证。

- 663 个原始裁片，663 个 normalized 页内坐标和 663 个资产哈希检查完成。
- 747 条图题/标签/标注节点，703 条在 IR 文本中得到忽略空白后的支持；44 条文本不一致保留为疑似信号，其中包括公式表示差异和一条正文污染。
- 162 条疑似信号：66 条图题父裁片几何信号、44 条图题与 IR 文本不一致、28 条正文引用标签未识别、15 条相邻未分组、5 条组合图号冲突、3 条标签序列缺口、1 条正文混入图题。一幅图可触发多条规则，**不是 162 幅确认错误图片**。
- 0 条上述确定性结构错误；1 条全书证据不足记录：原页像素尚未比较。报告整体仍为 `needs_review`。
- 88 个组合候选涉及 240 个裁片，511 个展示条目覆盖全部 663 个原裁片，独立结构校验 passed。语义质量仍为 unverified，本轮未重新安装候选到真实数据。
- 当前已安装关联取自 middle 导出的文本表示，因此桌面报告为 162 条疑似信号。本轮另用与当前 IR 同源的 structured_content 图题生成候选，747 条节点全部获 IR 文本支持，候选报告为 118 条疑似信号。同 IR/规则的差异报告记录 48 条旧信号不再检出、4 条新信号、115 条相同信号：其中 44 条为 IR 文本不一致，其余变化来自 3 条图题父裁片几何提示和 1 条正文污染提示的文本证据表示改变。信号 ID 按完整证据生成，证据改变会要求重新核查；不能解释为 44 幅图已修复或新增 4 幅坏图。两套报告和差异均保留，本轮候选未安装。
- 原始 IR、active manifest、lexical 快照 SHA-256 与修复前一致；本轮没有删除或重写原始裁片。

本轮新机制不能证明原解析已漏掉的线条、文字、子图是否完整，也不能保证发现全部错拆。要验证这些问题需要完整原 PDF/页图与裁片对应比较，必要时辅以 OCR/视觉候选和人工裁决。目前该书可用原解析裁片，未找到完整原页，不伪造这层通过结果。未调用付费模型。

- Python 3.10：审核、图学习、来源适配、IR、工作流和候选发布回滚回归 78 项通过；资产、适配器、探针和外部导入相关回归 32 项通过。

- macOS Electron 原生实例 `Texa Dev Validation`：`isPackaged=false`，appPath 为当前项目 desktop，backend 使用当前 `venv310`，前端是本轮重新构建的 `frontend/dist`；端口 58127、隔离数据 `/private/tmp/texa-dev-abc-20261004`。
- 实际 GUI 验证加载、筛选、空结果、原始裁片预览、分页，以及 1280×820、1024×768、760×820 三种尺寸。没有横向溢出，分页通过纵向滚动可达。

- 没有验收 Windows 或发布包，也没有更新旧打包应用；其他已运行的开发进程不会自动重载 Python 模块。
