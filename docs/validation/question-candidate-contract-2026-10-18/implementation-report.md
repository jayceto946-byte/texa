## 交付行为

- 显式 v1 教材分析从同次 Canonical 读取取得逻辑版本、安全来源块和原 LearningUnit；按整块生成题干、答案、解析提案。原 IR、全局 learning_units、阅读/RAG 和既有 fingerprint 均未修改。独立“证”段及公式伪题仅在候选侧做有界归并。
- 空答案、空标签不阻断普通题；明确解答块实际进入解析；同块混解、跨节、必要图片和前例条件保留具体问题。公式只在候选串行化补必要 display 包装，C021 等已有可读正文保持原字节和重复身份。源表文本与结构冲突会留待校对。
- 现有校对工作区新增内容/属性分类、本题来源块对照、问题定位、当前版本显式确认和可提交子集。拆并保全来源及源解，内容修改清空确认，元数据修改保留确认。修复窄窗从原文对照返回后正文仍被隐藏的问题；增加实际画布可见性检查。
- `/candidates/batch-add` 在写库前重放同范围来源和结构检查；校验版本、单元、完整 span 覆盖、依赖身份、正文及确认 hash。无效选定集合零写入；必要图不能通过 `embedded` 声明或泛化确认越过 F3。
- 新客户端核对分析版本回显，提交走独立 v1 路由；旧后端缺回显或提交路由降版时拒绝导入。旧分析、手工、文件及旧批量入口继续 legacy，不宣称享有新保证。
- 仅对新批次的既有 `exercise_import_batches.data` JSON 增加可选 `candidate_receipts`，无 SQL 迁移或 ExerciseRecord 扩展。回执与题目同事务提交；重复 skip 不给旧题补确认。已有回滚按原 JSON 更新，保留回执及未知键。批次核对消费来源、导入时确认类型及精确正文摘要；正式正文变更后只显示历史导入事实。
