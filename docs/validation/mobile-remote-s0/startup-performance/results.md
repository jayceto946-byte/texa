# S0 远程启动性能减重

2026-10-08；保持用户已有未提交修改，未改网络、鉴权、Runtime、数据库、教材索引或依赖。

## 确认的问题及改动

- 原 App 静态导入所有路由、工作区及公式输入模块。连接门槛虽不渲染其 children，模块仍先下载/求值。`App.tsx` 现在仅包含原连接门槛；鉴权通过后 lazy 加载 `Workspace.tsx`。原 providers、路由与业务状态原样移入 Workspace。
- 路由页面和设置内容 lazy 加载，加载提示由 Suspense 提供。远程工作区跳过已在连接门槛验证过的桌面FirstRunGuide模块，不下载其模型配置组件；桌面仍使用原首次设置流程。路由各自设置加载边界，保留 MainLayout 与已有持久路由缓存。
- 原 manualChunks 把依赖递归归入宽泛 vendor 桶；构建图显示启动依赖包含 Markdown/KaTeX。改为已有 Rolldown 的明确 React 高优先级组和图标组，其余遵循依赖图。修复两个公式组件静态引入 MarkdownRenderer 的入口，复用既有 lazy MarkdownMessage。无版本或 target 修改。
- 连接首屏使用 `shell.css` 基础主题/控件与原 Welcome 样式；完整工作区 CSS 与桌面字体仅在工作区加载。保持原连接页面，未新增移动布局。
- 入口在加载 CSS 前标记远程浏览器，远程字体使用系统字体。HarmonyOS 三个 TTF 合计约24 MB，远程不再请求；笔记字体 hook 同样跳过远程字体样式下载。Electron 保留原字体和主题。

- `backend/static_assets.py` 为成功的内容哈希JS/CSS设置immutable缓存，普通文件与404不缓存。`backend/remote_reads.py`仅优化GET会话列表/教材列表/连接就绪三个有限JSON端点，压缩并提供Server-Timing及仅含标签/状态/耗时/字节数的日志；JSON为no-store，鉴权在外层，SSE和写接口不变。
- 客户端原超时只覆盖响应头，JSON正文可能无界等待；有限JSON现在在同一个20秒deadline内读取。超时说明区分等待响应头与读取正文，不再把会话列表错误归因为模型识图慢；没有提高默认超时或自动重发请求。
