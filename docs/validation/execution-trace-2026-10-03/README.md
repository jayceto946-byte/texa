# 学习回答执行区验收（2026-10-03）

执行区保持在助手答案上方：运行时展示当前真实操作、最近两步和持续更新的时间；用户可随时展开。完成、失败、停止、输入门槛到达时自动收起。完整详情可用键盘打开。

详情来自现有 ExecutionEvent 的公开 payload，包含回答范围/必要输出、实际召回教材及段落预览、最终交给回答生成的 EvidencePack 选中段落、工具输入/结果摘要、校验与失败信息。召回和最终证据分别标注，不把全部召回冒充最终引用或答案支持。最多 12 段、单段 420 字预览，使用教材名与 chunk_id 共同匹配，避免跨书错配；截短和未保存预览明确标记。片段沿用 Markdown/LaTeX，禁用远程媒体。未知工具字段与隐藏思考不进入公开投影。

摘要用整轮 elapsed/total 时间，不累加重叠阶段。Runtime 工具事件按稳定 call_id 合并，事务重建 emitter 时仍从本轮创建时间计时；后续无详情的进度事件保留已有公开详情。没有数据库、索引或依赖格式迁移。
