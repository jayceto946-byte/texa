1. 使用隔离副本中的真实传感器教材 Chroma、ONNX embedding、词法索引和生产检索路径抽检三问。定义问返回 `supported`；“电阻式传感器两种材料各有什么特点，适用于什么场景？”也返回 **`supported`**，但最终 4 条 EvidencePack 均无“金属应变片”或“半导体应变片”，抽到的是应用、压电电路及电容式传感器等片段。这违反 R02/R05/R06 的逐项事实覆盖门槛，是当前可复现的**证据假阳性发布阻断项**。例 1.3 问返回 `partial`，不能算完整题目与解答验收。原始结果在运行目录 `real-retrieval.log`；没有调用回答模型，所以这里只评价检索及最终证据，不评价最终答案准确率。
2. 原生 Electron 开发端空 profile 显示首次配置；未填 API key 时阻止保存。隔离 profile 用占位 key 进入工作区后，教材页显示传感器教材及 13 章；图片审计界面显示 663 片段、162 可疑信号。这些数值是 UI/规则输出，不是 162 个人工确认错误，也不是 OCR 准确率。
3. 习题页对第 1 章执行“提取候选”，返回 22 个候选、20 个异常、16 个重复。未点击正式导入；候选含例 1.3 的题干、表和解答，但目录选择器可见明显 OCR 污染文字。需要对照原始页和人工校正后，才能承认 X01/X02 的题目事实和计算结果。笔记与错题页在隔离数据中只检查了空状态，未完成“笔记保存—作答—错题—SM-2 复习”的纵向业务链。
