# 笔记左侧预留的原生窗口核对

2026-10-19。该轮没有修改产品布局。

- `desktop/main.cjs:667` 使用 hiddenInset，原生窗口按钮位置为 x=18、y=11；真实 Electron API 回读一致，非全屏。
- 实际页面侧栏按钮 x=108，标题组 x=152。前一轮声明的 160px 是局部 CSS 的意图值，被更高优先级的共享样式覆盖；不可当作有效值。
- 浏览器 page.screenshot 没有捕获原生窗口控件。通过 CUA 保存的完整原生窗口截图，左上角当前显示系统紫色共享指示，说明该区域并非实际空白。
- 因此本轮只核对原因，没有把原生避让直接清零，也没有擅自增加独立标题栏或移动系统窗口按钮。是否改变原生窗口控件与页面命令栏的相对位置，是与单纯左对齐不同的布局选择。
- 截图：native-window.png；实际位置：native-geometry.json。数据为隔离自编样本，无远端模型调用。
