## (1) 求切平面 $T$ 的方程

先求偏导数：

$$f_x = 3x^2 - 2(x+y), \quad f_y = 3y^2 - 2(x+y)$$

在点 $(1,1)$ 处：

$$f_x(1,1) = 3 - 4 = -1, \quad f_y(1,1) = 3 - 4 = -1$$

验证 $f(1,1) = 1+1-4+3 = 1$，点 $(1,1,1)$ 确实在曲面上。

切平面方程：

$$z - 1 = -1\cdot(x-1) + (-1)\cdot(y-1)$$

化简得：

$$\boxed{x + y + z = 3}$$

## (2) 求 $f(x,y)$ 在 $D$ 上的最大值与最小值

**确定区域 $D$：** 切平面 $x+y+z=3$ 与三个坐标平面围成的有界区域是一个四面体，顶点为 $(0,0,0)$、$(3,0,0)$、$(0,3,0)$、$(0,0,3)$。其在 $xOy$ 平面上的投影为：

$$D = \{(x,y) \mid x \geq 0,\; y \geq 0,\; x+y \leq 3\}$$

$D$ 的边界由三段组成：$L_1: y=0\,(0\le x\le 3)$，$L_2: x=0\,(0\le y\le 3)$，$L_3: y=3-x\,(0\le x\le 3)$。

---

### 第一步：内部驻点

令 $f_x = 0,\; f_y = 0$：

$$3x^2 - 2(x+y) = 0, \quad 3y^2 - 2(x+y) = 0$$

两式相减得 $3(x^2 - y^2) = 0$，即 $x = y$（因为 $x,y>0$）。代入第一式：

$$3x^2 - 4x = 0 \implies x(3x-4) = 0 \implies x = \frac{4}{3}$$

驻点 $\left(\dfrac{4}{3}, \dfrac{4}{3}\right)$ 满足 $x+y = \dfrac{8}{3} < 3$，在 $D$ 内部。

$$f\!\left(\frac{4}{3}, \frac{4}{3}\right) = 2\cdot\frac{64}{27} - \left(\frac{8}{3}\right)^2 + 3 = \frac{128}{27} - \frac{64}{9} + 3 = \frac{128 - 192 + 81}{27} = \frac{17}{27}$$

---

### 第二步：边界 $L_1$（$y=0,\; 0\le x\le 3$）

$$h(x) = f(x,0) = x^3 - x^2 + 3$$

$$h'(x) = 3x^2 - 2x = x(3x-2) = 0 \implies x = \frac{2}{3}$$

比较各点函数值：

| 点 | $f$ 值 |
|---|---|
| $(0,0)$ | $3$ |
| $(2/3, 0)$ | $\dfrac{8}{27} - \dfrac{4}{9} + 3 = \dfrac{77}{27} \approx 2.85$ |
| $(3,0)$ | $27 - 9 + 3 = 21$ |

---

### 第三步：边界 $L_2$（$x=0,\; 0\le y\le 3$）

由 $f$ 关于 $x,y$ 的对称性，结果与 $L_1$ 完全相同：

| 点 | $f$ 值 |
|---|---|
| $(0,0)$ | $3$ |
| $(0, 2/3)$ | $\dfrac{77}{27}$ |
| $(0,3)$ | $21$ |

---

### 第四步：边界 $L_3$（$y=3-x,\; 0\le x\le 3$）

$$g(x) = f(x, 3-x) = x^3 + (3-x)^3 - 9 + 3$$

展开 $(3-x)^3 = 27 - 27x + 9x^2 - x^3$，与 $x^3$ 合并后 $x^3$ 消去：

$$g(x) = 9x^2 - 27x + 27 - 6 = 9x^2 - 27x + 21$$

$$g'(x) = 18x - 27 = 0 \implies x = \frac{3}{2}$$

比较各点函数值：

| 点 | $f$ 值 |
|---|---|
| $(0,3)$ | $21$ |
| $(3/2, 3/2)$ | $9\cdot\dfrac{9}{4} - 27\cdot\dfrac{3}{2} + 21 = \dfrac{81}{4} - \dfrac{81}{2} + 21 = \dfrac{3}{4}$ |
| $(3,0)$ | $21$ |

---

### 第五步：汇总比较

| 候选点 | $f$ 值 |
|---|---|
| 内部驻点 $(4/3,\, 4/3)$ | $\dfrac{17}{27} \approx 0.63$ |
| $L_1$ 端点 $(3,0)$ | $21$ |
| $L_2$ 端点 $(0,3)$ | $21$ |
| $L_1$ 驻点 $(2/3, 0)$ | $77/27 \approx 2.85$ |
| $L_2$ 驻点 $(0, 2/3)$ | $77/27$ |
| $L_3$ 驻点 $(3/2, 3/2)$ | $3/4 = 0.75$ |
| 原点 $(0,0)$ | $3$ |

**结论：**

$$\boxed{f_{\max} = 21 \quad \text{在}\; (3,0)\; \text{和}\; (0,3)\; \text{处取到}}$$

$$\boxed{f_{\min} = \dfrac{17}{27} \quad \text{在}\; \left(\dfrac{4}{3},\, \dfrac{4}{3}\right)\; \text{处取到}}$$
