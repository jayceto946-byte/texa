所有写入仅在 `/private/tmp/texa-focus-qa-data/goals.db`，Electron 使用临时 userData。桌面主进程及 preload 来自候选代码，不通过名称启动旧 Texa 安装包。邻页不调用模型。

1. 倒计时任务开始→教材→托盘暂停→学习页→继续；同一 session ID。后端重启后只恢复已提交部分，状态 paused。见 pre-recovery-snapshot.json。
2. 完成响应延迟 8 秒、前端 6 秒超时。初次抽查发现背景读取提前进入完成界面，修正 pending 轮询/投影门槛后重新验证。
3. 第二任务先倒计时结束，再选正计时新时段；延迟完成回执期间仍显示“保存结果待核对”，控制禁用。刷新 renderer 后没有数据也保留核对入口；读取原 operation receipt 后完成。goal-qa 的 3 个 session ID 前后相同，见 lost-reply-comparison.json。
4. 最新窗口 1280×820：聊天页延迟挂载 composer，控制面板改为 sheet 避让。760×820：目标详情单栏、返回目标列表，任务行按钮可读；专注 sheet 不裁掉主要操作。1024×768 的聊天托盘截屏单独保留。
5. 手动创建“QA 手动学习目标”，不填写说明或完成条件，不点击“帮我整理”。Enter 连续添加“阅读指定章节并写下定义”“独立完成选定例题”“核对解法并记录错因”“复述定义并检查条件”。第四项上移后队列顺序正确。
6. 草稿目标行点“开始学习”，激活目标并复用最近正计时偏好。勾当前任务：时段 ended，任务 completed，面板显示下一项，下一项没有自动开始。撤销完成：任务 pending，原时段仍 ended。点“开始新一段”：新 session。
7. 上述队列添加最初重新弹出旧任务完成面板。修正完成身份边沿判断后再次添加第二、第三、第四项，面板不重开；4 项自动测试覆盖等待回执、重复更新及重新完成。
8. 复习样例 DTO 修正后，从复习恢复同一时段，依次学习→教材→笔记→练习→复习；截图均有同一任务托盘。routes-before/after 中 session/task ID 一致、都 running、历史仍5条。期间没有后端重启。
9. 原生 Command+W 关闭窗口。读取临时 API：同一 session 状态 paused，reason shutdown，见 after-native-close.json。重新打开当前 wrapper 后仍暂停，不自动继续。
10. 新建“QA 输入焦点验收”，仅填标题直接保存；原生 AX 确认焦点进入“添加一项具体任务”。本目标不启动，原暂停时段没有变化。

这不是录像或真实系统休眠验收。具体时长仅为临时验证记录，不作为用户学习成果。
