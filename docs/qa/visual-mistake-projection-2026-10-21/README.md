# 图片题转错题的视觉结构化内容泄漏修复

用户反馈：学习会话图片题加入错题后，题目显示 visual-problem-ir/v2 JSON、实体位置、关系和 LaTeX 中间标记。

根因是两处边界混用：识图 JSON 解码失败后会把整段结构化输出作为纯 OCR 转写；聊天捕获又直接以含图形说明、标注、关系等辅助信息的完整会话文本作为错题正文。旧错题页面直接将该字段传入数学 Markdown 渲染，进一步放大了格式问题。

## 实施

1. 视觉模型输出只修复 JSON 字符串内的 LaTeX 转义，不补题意或补 JSON 字段/闭合结构。合法 JSON 转义保持不变；损坏的结构化输出明确失败，普通纯文字 OCR 及带 [37] 等题号的正文继续兼容。
2. 题干/选项使用独立投影；内部实体、位置和关系保留在 visual_ir，原图、用户作答和完整答案继续独立保留。捕获与正式收录保持原幂等及人工确认流程。
3. 前端兼容旧视觉 JSON、嵌套 JSON 及旧会话辅助段落，覆盖主聊天、错题列表/详情、草稿和档案编辑、复习题目。结构化结果不完整时展示校对提示，编辑框为空，不把提示自动作为题干。没有数据库迁移或批量改写历史记录。

## 验证

- Python 3.10：7 组相关测试 **100 项通过**。包含同类原始 OCR JSON 经图片问答、会话持久化、错题草稿、显式校对及正式收录的全链路；校验正文中没有结构字段，原图字节与任务视觉 IR 保留，重复捕获仍幂等。
- 前端：52 文件 **248 项通过**；lint 和生产构建通过。既有 MathLive 大 chunk 提示保留。
- macOS Electron 37：生产 frontend/dist + 临时 userData + 只读夹具，**29 项通过**，无 renderer 异常。1280×820、1024×768、760×820 下旧误存记录与新记录均保留题号和完整公式，KaTeX 正常，无结构化字段或 MATH_PROTECTED 标记，无水平页面溢出；旧档案和草稿编辑框、列表展示也通过。
- 夹具按用户截图构造，不是重新调用 OCR 模型。没有发送用户图片到外部服务，也没有修改正式学习数据。Windows 原生 UI 未实测。
