## 实施

- 桌面导航恢复直接 nav 结构，手机 details 折叠容器只在窄屏使用；历史、设置固定入口及原主题保留。
- 目标页以目标描述、折叠完成条件、番茄任务和当前计时为主；任务使用序号、时长、手动完成状态；模型辅助/旧 Runtime 控制与执行记录成为可展开次级区，运行/等待用户输入或确认时自动展开。既有权限、恢复门槛与运行链路未改。
- 创建任务表单按需展开；当前计时在目标页以清晰数字呈现，在聊天页保留紧凑可展开控件。计时不自动完成目标或写掌握状态。
- 缓存页面切换使用170ms轻淡入/4px位移，不卸载工作区、丢弃草稿或中断SSE。窗口/弹窗打开140–180ms淡入，复用现有Dialog焦点/关闭合同；减少动态设置禁用动效。
- 新增独立“手机连接”设置分类，与“偏好”“模型连接”“数据与教材”等并列；不再放在关于或偏好中。界面无CLI命令、固定端口或S0标签。
- 本地Electron IPC执行固定Tailscale参数（execFile，无shell或用户任意命令），读取当前真实backendUrl；一键开启/关闭、复制地址/临时配对码。配对码沿用现有进程临时凭证，不放入URL、日志或状态文件。
- 一键开启成功后保存启用状态与上次本地目标，后端真正ready时恢复Serve；实际重启验收发现初始恢复过早，已修正到ready转换，并复验通过。
- 当前DNS/443根路由只接受当前或上次Texa目标；其他当前主机服务冲突时拒绝，不重置全部Serve，不启用Funnel。更名后的旧主机配置保留、不覆盖；旧MagicDNS名称不再解析。
- 按用户明确选择，将本机Tailscale设备名改为texa；HTTPS仍需要tailnet后缀。新地址 **https://texa.tailb31d35.ts.net/**。旧地址不再作为入口。
- 新desktop/remote-connection.cjs加入Electron打包文件清单；无依赖安装、无数据库结构升级、无付费模型调用。
