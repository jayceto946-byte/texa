参考用户提供的 [Claude Design System Storybook](https://claude-storybook.bystanderss.chatgpt.site/) 中的控件尺度、菜单圆角、浮层层次及约 200ms 动效建议。该页面是第三方设计参考，未将其当作 Claude 官方产品合同。Texa 保留自己的蓝色选择状态、学科层级及教材范围语义。

## 历史与置顶

同一份历史列表保持挂载，主导航展开时回到原侧栏；只有学习页主导航折叠时显示左边缘入口。悬停拉出、离开收回，保持 220ms 位移动画与 180ms 离开缓冲；支持点击、键盘和减少动态效果设置。

学科与更多操作浮层按各自 ID 登记，指针进入浮层视为仍在历史范围内。离开抽屉及浮层后一起收回；关闭抽屉只重置浮层，不清除列表分页、筛选或会话状态。置顶改为独立轻量分组，移除粗上下边框，保留当前会话选中样式及原有幂等管理接口。
