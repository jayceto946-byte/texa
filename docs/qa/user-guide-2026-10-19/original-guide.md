# Texa 用户指南

> 适用于当前 `Texa_MacOS` 开发工作树的操作指南草稿，更新于 2026-10-19。界面入口与保存规则已对照当前源码；安装包、真实模型与解析服务、跨平台行为、备份恢复和手机连接尚未在候选发行包上逐项实测。发布前须按 [用户指南内容规格](TEXA-USER-GUIDE-SPEC.md) 的 V01–V18 验证并补上对应截图。本文不代表这些场景已经验收通过。

Texa 是围绕教材、提问、练习、错题和复习记录使用的本地学习工作区。你可以先连接回答模型并提问，教材和学习目标都可以以后再加。学习记录主要保存在这台电脑；使用远程模型或解析服务时，完成该功能所需的内容会发往你配置的服务。

## 从这里开始

- **第一次使用**：读[连接回答模型](#连接回答模型)，然后到[提问与核对答案](#提问与核对答案)完成一次问答。
- **已有教材**：从[导入教材](#导入教材)开始，接着[选择回答范围](#选择回答范围)。
- **想做题**：从[准备题目](#准备题目)开始。导入教材本身不会自动建立题库。
- **想安排今天的学习**：直接看[目标任务与专注](#目标任务与专注)。

### 第一次学习的最短路径

1. 打开 Texa。首次使用时，在引导中连接回答模型；已有配置的用户直接进入“学习”。教材可暂时跳过。
2. 先用“测试文字连接”检查服务，再选择“保存并继续”。在“学习”中问一个范围明确的问题，例如“请解释导数的几何意义，并给出一个例子”。看见配置已保存，只说明设置已写入；以真实收到回答为连接验证。
3. 如果已准备好可复制文字的 PDF，按[导入教材](#导入教材)把书加入“教材”，设为学习范围。再次提问时点开回答的来源，对照教材原文检查关键定义、条件和计算。
4. 想把这次讨论留作复习材料时，从该会话的三点菜单选择“整理为笔记”，生成并检查草稿，再点“保存笔记”。回到“笔记”的“已保存”列表，重新打开它。

没有教材时也可以问普通问题，但普通回答不能当作教材引用。笔记、题库和错题的正式保存都有各自的确认步骤。

## 开始使用

### 打开 Texa

请使用与你的系统相符、由发布方提供的安装包。当前仓库不能证明安装包已经发布、签名或完成所有系统兼容验收，因此本指南不提供未经核实的下载地址或最低系统版本。第一次打开后，按屏幕上的引导连接回答模型；已有配置通常会直接进入工作区。

如果启动停在错误页面，先记下应用版本、系统和完整错误提示，使用界面上的重试或诊断入口。先不要删除本地数据或重装学习资料。教材不是首次进入工作区的前置条件。

### 连接回答模型

首次引导与“设置 → 模型连接”都可以管理连接。你需要知道所用**服务商**、准确的**模型名称**，以及该服务要求的 **API Key**（模型服务的访问密钥）。密钥应从服务商的正式渠道取得，不是服务商网站的登录密码。使用自定义服务时，还要按服务商资料填写 **Base URL**（服务地址）和 Model ID；显示名称只用于自己辨认。

1. 选定回答模型并填写所需信息。只做文字问答时，先完成这一项。
2. 点“测试文字连接”，看测试反馈。测试会访问服务，可能产生调用费用；测试成功并不会替你保存草稿配置。
3. 首次引导中点“保存并继续”；在设置中修改字段后点“保存并应用”。切换已经保存的方案可能立即生效，编辑方案中的字段仍需保存。
4. 回到“学习”发一条实际问题，确认能收到回答。若要做图片题，再单独使用“测试识图能力”并发送一张可公开的测试题图。

单模型方案要求同一个模型具有所需的文字与图片能力；双模型方案分别配置回答与识图。文字测试通过，不表示图片一定能识别。更换服务后密钥输入框留空可能表示保留原密钥，应看界面状态，不要把空框当作密钥已删除。Texa 本身不提供无限量免费模型调用；费用、额度和服务可用性以你所选服务商的当前说明为准。

连接失败时核对服务地址、模型名称、密钥、网络与服务额度，保留去掉密钥的错误提示。请求超时或被停止也可能已经发生服务调用，不要连续重复点击。

## 围绕材料学懂一个问题

### 导入教材

在“教材”进入“导入教材”。教材入口接收 PDF 或完整的 MinerU ZIP 输出包；练习题文件使用另一个入口。

**可复制文字的 PDF**：先在普通 PDF 阅读器里试着选中并复制一小段正文。选择“PDF 教材”、文件、所属科目和“本地文本提取”，需要时填写目录页范围，再点“开始导入”。这一路径读取 PDF 自带的文字层，不做 OCR。等待页面显示教材已可用于学习，回到教材列表检查记录并“设为学习范围”。接着用书中一个明确概念试问，检查来源是否对应原文。

**扫描件或复杂版面**：如果页面实际上是一张张图片，本地文本提取可能得不到正文。界面显示 MinerU API 或 CLI 可用时，才选择“MinerU 解析”；已有完整外部解析结果时，可走“MinerU 输出包”，保留 ZIP 原有目录结构。两者都没有时，先准备解析条件，不必反复用文本提取重试同一扫描件。

导入期间看当前进度与最终状态；“正在准备”不等于可检索。可选的概念抽取可能在教材可用后继续，失败也不一定需要重新导入整本书。目录页范围和练习抽题的“物理页”是文件页序，可能与书上印刷页码不同。导入完成也不保证公式、表格或 OCR 文字完全正确；遇到关键内容要对照原页。中途退出或重启后的导入恢复尚未做发行包验证，不要据此假定有断点续传。

### 选择回答范围

在教材列表可将一本书“设为学习范围”；在“学习”的范围选择器中，也应在发送前确认当前教材或学科。只选学科与选定一本教材的检索范围不同；通用回答则不提供这本教材的依据。重新打开旧会话后，再看一眼当前范围，不要假定仍沿用之前的选择。

多本资料配套时，可在教材管理中按科目、分类及“主要 / 辅助 / 独立”角色整理。主要教材并不保证回答只引用这一本书，最后仍要看实际来源。如果要问某章，请把章节名和具体问题写进提问；当前主聊天没有可依赖的独立章节下拉框。

### 提问与核对答案

一个好问题要写明对象、已知条件和想得到的结果。例如：“按《某书》第三章，说明阻尼比的定义，并解释式中各量的单位。”公式推导可要求逐步展开；另一本书或另一道题最好新开会话。追问时可以说“上一步第二行为什么成立”；如果上一轮对象或条件有误，直接明确纠正。长会话中的精确条件建议重述。

输入区按 Enter 发送、Shift+Enter 换行。回答过程中可看到阶段与执行记录；正文出现不等于每个结论已经核实。教材型回答请打开来源，核对定义、公式、参数、单位和使用条件。来源能帮助追查依据，但不是“答案绝对正确”的证明。回答标成依据不足、未核实或降级时，依提示检查教材范围与材料；界面明确提供通用回答选项时，只有你主动选择后才把它作为普通解释阅读。

缺另一页、附表或关键题图时，回到**原任务**按其提示补充支持的图片；没有材料时可在界面允许的情况下选择只讲方法，不应期待精确数值。停止或断线后，先看原任务是否出现继续入口，再决定下一步。若页面出现学习记录或写入提案，需明确确认才会正式写入；拒绝也不会把模型文字当成已保存记录。

会话三点菜单可用于置顶、归档、移入回收站和整理笔记。回收站中的会话要先恢复才能继续提问；若界面提示有未完成任务，先继续或明确结束该任务。会话管理不会自动删除独立笔记或错题。

### 输入公式、图片题与教材插图

输入公式时，可以用输入区的公式工具选择模板并填写变量；矩阵按格填写。发送前检查上下标、括号、条件和单位。若问题里有多个公式，请写明“按公式 (1)”等引用方式。

桌面端图片题从图片文件加入输入区。先确认题干、图、选项、附表和页码都在画面内；裁剪局部时不要把计算所需条件裁掉。若界面提供可编辑的识别文字，应先对照图片改正再发送。识图模型读错一处参数就可能影响整个答案，最终计算仍需核对原图。

已有教材图片可从教材图目录搜索并选择整图或局部区域；目录没有搜索结果，不表示原书没有图。补充材料控件目前按图片使用，不应当作任意 PDF 或 Word 附件入口。遇到缺另一页或附表，沿原任务补图；暂时没有图时只讨论能确定的方法。

### 把会话整理成笔记

在需要保存的会话三点菜单选择“整理为笔记”。可以整理全部会话，或加载更早轮次后自行勾选部分轮次。检查来源范围，再生成草稿。草稿可以编辑标题与正文，按需关联教材分类或章节；AI 整理可能适度补充解释，并非原对话逐字摘录。

看到“草稿已保存”只说明**草稿**已写入。读完并改好后，点“保存笔记”，再到“笔记 → 已保存”重开检查。以后继续聊同一会话，不会自动把新内容添进这篇笔记。修改正式笔记后也要点“保存修改”；历史版本和归档在笔记详情中查看。

生成失败时先保留来源会话和现有草稿，再从同一来源重试或自主整理。重启不会自动重新发起付费生成。若编辑时提示版本冲突，先保留自己的修改，再按页面提示核对版本，不要反复覆盖。

## 通过做题找到薄弱点

### 准备题目

“教材”用于问答检索；要开始练习，还需要把题目放进“练习 → 题库”。进入“练习 → 导入”后，选择从已导入教材抽取，或导入 `.docx` / `.pdf` 题目文件；有独立答案文件时按界面单独提供。也可以手动录题。

1. 先用少量文字完整的题目试一次。教材抽取可指定章节或物理页范围；这里的物理页可能不是书上印刷页码。
2. 分析后进入“校对候选题”。**候选题是尚未入库、需要核对的题目**。点“原文对照”，逐题检查题干、所有条件、答案和解析是否分开，必要时编辑、拆分或合并。
3. 对需要人工确认的题点“确认本题结构”。修改题干等内容后，之前的确认可能失效，要按当前版本重新确认。
4. 只选择内容完整、页面允许入库的题，点“确认入库”。查看新增、跳过重复和待处理的回执，再到“题库”打开其中一道题核对。

缺难度或标签与缺图、缺条件不是一回事。必要附图即使被定位，当前也不一定能作为独立练习题交付；不要通过删除图号绕过完整性检查。文件分析和教材抽题的校对能力也可能不同。原材料没有答案时，不要把空答案当作标准答案。正式题目阅读页的题干目前只读，入库前应认真校对。

候选主要保存在当前页面内存中，切页缓存不能当作重启恢复。入库结果不明时，先“核对导入批次”及题库，不要反复点提交。批次撤销会影响已入库内容，应看清目标批次后再操作。

### 做一轮练习

在“练习”选范围、题量和顺序后开始。先写自己的思路和步骤，再看参考答案；最后从“没掌握 / 基本理解 / 已掌握”选择一档并确认提交。连续练习会进入下一题；完成后回看本轮记录。单题练习也可以使用。

这里的三档是**你对本次练习的自评**，不是自动阅卷或独立重做成绩。暂停、结束本轮与保存当前作答不同；结束前确认当前题已提交。题库没有参考答案时，可以使用“AI 解题”产生草稿，自己核对、编辑后再点“保存到题库”。看见 AI 草稿不表示参考答案已保存，离开后也可能找不到。

如果作答后出现错题候选，沿“确认收录”进入下一步；候选出现并不等于正式错题已建立。

### 收录错题

从练习产生的“待确认收录”进入，逐项核对题干、当时作答、参考答案和必要图表，保存校对后再确认收录。完成后到“错题”的正式档案重开该题，确认可以“现在重做”。

手上只有图片或手写题干时，可从错题录入开始。OCR 得到的文字需要你逐字检查和修改；题干、关键条件与附图完整后，再点“保存并安排复习”。暂时缺材料时可以保存草稿；不知道错因时可以稍后再写，不能为了收录猜测错因。手动标记掌握与随后独立重做留下的证据不同。

### 完成一次复习

在“复习”先检查当前范围和到期内容。有错题时，“开始本次复习”通常进入错题会话；概念复习是另一段流程。做错题时先独立写下本次答案，可保存草稿，然后“提交作答并查看反馈”。看过参考后，从“不会或做错 / 部分完成 / 有提示后做对 / 独立做对”选择真实结果并提交。空白作答不能算独立做对。

完成后回到复习队列，看结果与后续待办；概念卡片需另行展开、理解并记录本次复习。仅打开答案不等于完成复习。空队列表示当前范围没有到期项目，不等于所有知识都已掌握。统计样本少时，也不要把诊断趋势当成确定结论。

## 持续学习

### 目标、任务与专注

目标写想达到的结果，例如“完成第三章复习”；任务写今天能做的动作，例如“做 8 道课后题”。在“目标”新建目标，填写标题及可选完成条件，保存后再添加具体任务。**保存目标不会自动启动 AI。**

选一项任务开始专注，可选倒计时或正计时；需要时暂停、继续、切换任务或结束本次。倒计时到点只记录投入时间，不会自动把任务判成完成。做完任务后主动点“完成任务”；整个目标是否完成还需另行确认。暂停计时不等于停止 AI 辅助，搁置目标也不是单纯关闭计时面板。电脑睡眠、退出和手机同时操作时的时间记录尚待发行包实测，重开后以可见记录核对。

### 按需使用 AI 整理与报告

目标内的 AI 辅助需要你明确启动；等待输入或写入确认时，先看当前任务给出的原因与实际可用入口。当前目标页可能显示缺材料，却没有与主聊天相同的补图入口，不应假定一定可以原地上传后继续。定时安排也依赖这台电脑上的本地服务运行，关机后不会由云端代跑。

“学习”输入区的“学习操作”菜单可查看或生成章节重点，也可打开学习日报、周报等入口。章节重点按教材范围整理，笔记来自你选择保存的会话，日报/周报汇总已记录的学习活动，三者用途不同。重新生成重点前先看已有成果；报告只用于回顾和安排下一步，不是能力评分。

## 保存数据与解决问题

### 哪些内容已经保存

| 内容 | 何时算完成 | 离开前检查 |
|---|---|---|
| 模型配置 | “保存并继续”或“保存并应用” | 连接测试不会替你保存配置 |
| 会话 | 后端完成当前问答或任务状态记录 | 停止、断线后回原任务看继续状态 |
| 笔记 | “保存笔记”或“保存修改” | “草稿已保存”不等于正式笔记 |
| 导入题目 | 取得入库回执并在题库重开 | 候选未入库前可能随刷新或退出丢失 |
| AI 参考答案 | “保存到题库” | 仅看见生成草稿不算保存 |
| 练习作答 | 自评并确认提交 | 未提交的文本不保证重启后保留 |
| 错题 | 校对并“确认收录”，或“保存并安排复习” | 草稿、待确认候选都不是正式错题 |
| 错题复习 | 提交作答后确认本次结果 | 仅揭示答案不算记录结果 |
| 目标与专注 | 各自操作得到保存或完成回执 | 计时到点、任务完成、目标完成分开 |

### 备份、恢复与更新

在“设置 → 数据与教材”中创建学习数据备份。默认覆盖教材、章节、习题、错题和学习记录；可选择同时备份体积较大的向量检索与 MinerU 产物。创建后查看“校验通过”和备份详情，记下保存位置。备份不包含 API Key。

**恢复前请先停下核对。** 界面按钮目前叫“合并恢复”，但实际恢复会按备份所含的数据目录进行替换；同一个目录中备份日期之后新增的记录可能被覆盖。未包含的其他数据目录才会保留。系统会先创建恢复前安全备份，恢复在重启时执行；这不等于每一种故障都已证明可以自动回滚。正式学习资料上不要用旧备份做试验。必须恢复时，先确认备份日期、包含范围和当前数据的安全副本；重启后分别核对教材、会话、笔记、作答、错题和目标，而不是只看“恢复已登记”。跨电脑迁移与旧版兼容仍需另行验证，迁移后模型密钥也要重新配置。

“关于与更新”可查看当前版本和可用动作。存在检查更新入口，不表示当前一定有可下载更新。更新或启动失败时保留备份与错误信息，先检查本地服务状态，不要先清空数据目录。

### 手机连接（可选）

“设置 → 手机连接”用于让本人手机访问**这台仍在运行的电脑**上的工作区。按页面检查准备状态；若需远程连接，电脑和手机应按当前提示准备 Tailscale，并用本人设备开启连接、复制地址、在手机浏览器配对。配对码只输入本人手机，不要发到公开聊天或截图。桌面重启后可能需要重新配对。

手机访问的是电脑上的同一份资料，不会生成独立同步副本。电脑关机、本地服务停止或连接条件不满足时，手机无法像云服务那样独立使用。该路径仍需当前候选发行包和手机实测。

### 遇到问题，先检查当前状态

| 遇到的情况 | 下一步 |
|---|---|
| 不能回答 | 看模型连接的测试反馈、当前方案、网络和额度；保存设置后发一条实际文字问题。 |
| 教材答不出或说依据不足 | 看教材是否已可用、当前学科/书是否正确、来源是否覆盖问题；不要用通用回答冒充教材结论。 |
| 等待附图、附表或确认 | 回到原会话和原任务，按显示的缺项补充支持的图片，或明确选择只讲方法；写入提案需本人确认。 |
| 题目或答案“刚才还在” | 查候选是否入库、AI 答案是否“保存到题库”、练习是否提交；结果不明先查题库与导入批次。 |
| 笔记或错题找不到 | 分别检查“草稿 / 已保存”、错题“待确认 / 档案”，以及当前筛选、归档和回收站。 |
| 复习为空 | 检查范围、是否已有正式错题或概念记录、是否真的到期。 |
| 重启后资料看似消失 | 核对当前包、数据位置、学科范围和归档状态；保留现有文件与备份，使用高级诊断记录脱敏错误。 |

向维护者反馈时附上版本、操作系统、问题发生前的操作、页面可见状态和去掉密钥及私人教材内容的错误信息。不要通过反复提交未知结果、删除数据库或重导全部教材来试探故障。

## 常见问题

**没有教材能先用吗？** 可以。先连接回答模型做普通问答；以后再导入教材。普通回答没有教材来源。

**扫描 PDF 为什么没有正文？** “本地文本提取”不会 OCR。可先试复制文字；扫描件需要可用的 MinerU 解析服务或完整输出包。

**答案有来源就一定对吗？** 不一定。打开来源核对关键定义、公式、数字、单位和条件；未核实的结论仍需自己判断。

**教材导入了，练习里为什么没有题？** 教材检索和题库是两步。到“练习 → 导入”抽取或导入题目，逐题校对并确认入库。

**笔记显示“草稿已保存”，为什么在“已保存”里找不到？** 草稿与正式笔记分开。回草稿检查内容，点“保存笔记”后再去已保存列表查看。

**做错后为什么没进错题本？** 练习可能只创建待确认收录候选。校对题干与作答并确认后，到正式错题档案检查。

**自评“已掌握”与“独立做对”相同吗？** 不相同。前者是练习中的自评；后者是在错题复习中先独立作答、再确认的本次表现。专注时长也不会自动提高掌握状态。

**断网还能做什么？** 已保存的本地资料能否阅读或编辑，还取决于 Texa 本地服务是否正常；远程模型生成和外部解析需要对应连接。先区分“模型服务不可达”和“整个应用打不开”。

**“合并恢复”会留下备份后所有新记录吗？** 不能这样理解。备份所含目录会被替换，同目录后来新增的记录可能被覆盖。先核对备份范围并保留当前安全副本。

**关掉电脑后定时 AI 还会运行吗？** 不会由云端代跑；本地服务停止时不能继续执行。错过任务在重启后的具体处理仍待发行包验证。

**手机连接后是否同步了一份数据？** 没有。手机访问的是正在运行的这台电脑及其当前工作区。
