# 内置用户指南：实现与验收

日期：2026-10-19。基线：`Texa_MacOS`，HEAD `1dc9adc` 加本次未提交工作树。工作区原有导航、会话菜单、样式和 patch notes 修改保留，没有切换工作区、迁移数据库或改动学习数据。

## UI 审查与集成决定

| 现有能力 | 审查结果 | 集成处理 |
|---|---|---|
| `FirstRunGuide` | 欢迎 → 模型连接 → 进入工作区；完成标志与已配置模型共同控制首启门槛 | 保留，不再做第二套新手教程 |
| `AppRail` | 常驻产品导航；窄窗通过展开侧栏及“功能与设置”访问 | 在设置上方增加“用户指南” |
| `SettingsDialog` / `SystemHealth` | 共用 Dialog；设置分类、未保存模型退出确认已存在 | 复用弹窗，只增加按分类打开的参数，关闭后保留指南步骤 |
| 教材 `OptionHelp` | 解析方式、可用性、扫描件限制已有就地说明 | 指南只解释选哪条路径，不复制参数百科 |
| 练习 `HelpHint` / 候选工作区 | 题库与导入视图、结构确认、原文对照、入库回执已有 | 复用；在导入/校对区域增加候选刷新与退出丢失提示 |
| 练习答案 `ExerciseReader` | 未保存 AI 草稿已有提示与离开保护 | 保留，不再增加弹窗 |
| 笔记草稿与正式笔记 | 自动保存状态与“保存笔记”按钮并存 | 用真实草稿阅读页截图明确区别 |
| 备份恢复 | UI 名称“合并恢复”容易掩盖 `backend/data_backup.py` 对包含目录的替换 | 改为“从此备份恢复”，在操作区和原有确认框说明覆盖后果；不改恢复逻辑 |

集成方案在实施前已向用户说明：独立 `/guide` 阅读页，四场景，一次一个步骤，真实截图可放大，提供对应页面或设置入口。没有强制弹窗、进度收集、模型生成教程、外链依赖或新引导状态持久化。

## 截图与环境

截图由 `scripts/qa-user-guide-electron.mjs --capture` 自动操作真实 macOS Electron 37，使用当前工作树构建出的生产 React。数据来自只读样例 API；userData 独立放在临时目录；没有访问正式学习资料、凭证，也没有调用模型或 OCR。示例回答不是人工教材金标。图片由 Playwright 直接截图，没有绘制或拼接 UI。

应用内图片位于 `frontend/public/guide/`，涵盖模型连接、学习、来源、笔记草稿、教材管理、教材导入、练习导入、练习准备、错题、复习、目标任务、备份。每张图有场景 alt，标注“当前桌面界面 · 示例资料”。放大复用 Dialog，支持 Escape、焦点圈定及返回触发按钮，窄窗原图可以滚动查看。

指南界面证据：`1280-first.png`、`1280-textbooks.png`、`1280-practice.png`、`1280-manage.png`，以及对应的 `1024-*`、`760-*`。额外保留笔记/恢复警告和操作入口、graphite 主题截图。尺寸分别为 1280×820、1024×768、760×820。按 `texa-ui-system` 的颜色、字阶、阅读画布、按钮及间距角色实现；未扩展其他业务页面结构。

- 三种窗口尺寸检查场景切换、上/下一步、标题焦点、截图加载与放大、Escape 及焦点返回、侧栏收起后重新访问。另查非法 URL 参数回退、刷新后定位、场景方向键与主题偏好。
- 教材与候选导入的真实完成、模型回答质量、笔记正式保存、作答与复习写入、计时恢复、备份/恢复/更新和手机连接**没有因为入口可达而被记为业务通过**。
- 当前候选发行包、Windows、真实模型/OCR、真实恢复覆盖和手机均未测；完整待办见 [release-checklist.md](release-checklist.md)。
