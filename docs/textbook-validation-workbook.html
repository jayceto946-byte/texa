追加真实问题用例

每个问题单独记录，避免把整章或多本书的结果混为一项。主教材建议先做 30–50 个真实问题，覆盖主要章节；其他教材也要检查各主要章节和特有结构。

如何选样本、判断回答是否正确？

先从原文选取定义、列表、公式、表格、例题及跨页内容，写好正确章节与必要要点，再提问。题目类型覆盖定义、列举、比较、原理、推导、应用、跨章节及负向问题。回答正确性由你对照原文判断；自动校验通过或引用存在，都不能单独证明答案正确。每个样本分别记录证据、答案和引用的结果。

整理反馈

导出的报告包含环境、全部步骤和问题用例，保留待验证、不适用及首次失败的描述。把 JSON 或 Markdown 文件发给我，就能按编号定位和修复。
