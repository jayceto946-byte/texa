# Texa Icon System — 初步规范

2026-10-30 · Audit + Exploration + Prototype。三方向均为手工编写的原创 SVG 几何；现有栏的 Lucide 仅作对照，不作为原创资产。用户已授权将最终 A 方案接入软件；未设计的其他图标继续沿用现有资产。

## 访问与文件

在仓库根运行：

```sh
cd frontend
npm run dev -- --host 127.0.0.1
```

打开 http://127.0.0.1:5173/icon-design.html 。这是独立 HTML 开发入口，沿用 React/Vite/TypeScript，无新增依赖；不经过产品 Router、远程登录门槛或业务 Provider。默认生产构建只打包 index.html，设计板不进入桌面发行包。Electron renderer 可直接加载该 URL；本次已用隔离 Electron 37 窗口验证。正式桌面启动入口不变。

- A 几何权威：`frontend/src/components/icons/geometry.ts`；设计板的 `geometry.ts` 引用同一份 A，B/C 仍只供探索。
- 正式 React 组件入口：`frontend/src/components/icons/index.tsx`，导出 TexaSearch、TexaMistakes 等 20 个语义组件；设计板组件独立保留。
- 静态矢量：`docs/design/icons/{A,B,C}/*.svg`，60 个基础图标、6 个 16px 减笔版（A 抽取 + C 五枚）。
- 重导出：在仓库根运行 `node scripts/design/export-icons.mjs`，使用项目已有 TypeScript 开发依赖。改几何后一起更新导出文件；不独立改导出 SVG。
- 审计再生成：`node scripts/design/audit-icons.cjs`。库存 JSON 提供引用上下文，Markdown 供评审。

## 画布与造型

| 项目 | 当前规则 | 理由 |
|---|---|---|
| 坐标 | viewBox 0 0 24 24 | 不随使用场景改坐标系 |
| 常规显示 | 16 / 20 / 24，32 仅作放大评审 | 18px 导航也可使用同一组件；不把现有导航强制改成 24px |
| 描边 | 1.8 单位，随尺寸缩放 | 16px 约 1.2 CSS px；不加 non-scaling-stroke，否则四种尺寸重量关系改变 |
| 边界 | 主体一般 x/y 3–21；带操作的外伸可至 22 | 留出端帽与斜线空间，避免 viewBox 截断 |
| 页形 | C：x4–20 / y3–21；书脊 x8 | 以 16×18 竖向主体区别通用方框 |
| 曲线 | 搜索保留圆形；书籍与操作以直线为主 | 曲线服务成熟识别；不因“去 AI 感”禁止曲线 |
| 端点/转角 | square cap / miter join；不使用滤镜/阴影 | 给开放线段稳定落点；避免依靠圆角区分方向 |
| 填色 | 仅 currentColor，局部实心 path 显式 stroke=none | 防止实心块被描边二次加粗 |
| 路径复杂度 | 每枚 1–3 个路径元素，少量直线/圆弧命令 | 可直接审阅维护；不引入轮廓描摹和大量无效节点 |

A 以线框为主：打开的书、括号等价检查、固定步骤组合；B 以书脊、标题带、箭头实心面控制重心；C 在学习资产中采用页边索引，将“段落”与“操作”联系起来。C 的目标保留旗帜，学习保留对话框；搜索、关闭、返回不套页框。三个方向共用基础工程规则，差异来自轮廓、负空间和面线关系。

## 光学校正与小尺寸

不能用“1.8 一致”代替光学判断。圆形搜索使用更宽的圆轮廓，窄纸页使用 16×18 主体；编辑工具保留斜向轮廓；A 的验证勾选缩小后放在括号内右下留白处，B/C 仍保留探索版外伸动作，避免把所有形状硬塞进同一正方形。C 的实心页边只占局部段落高度，以免侧栏全部出现黑色竖条。

16px 的 C 检索去掉第二行正文；抽取去掉页内细字；验证去掉次要等式线；执行去掉中间分支；命题去掉第二条题干。保留书脊、动作箭头/勾和必要负空间。设计板及单枚导出根据数值 size <= 16 选择这些结构；不要用 CSS 单独缩小 24px SVG 来冒充减笔版。

当前 A 的抽取在 16px 去掉中间短线，其余 A 与 B 使用基础图形。A 的题库短线与 B 的实心删除在 16px 是继续打磨项，不能据本次原型宣称全库已达发布质量。16px 的最窄缝隙与 1.8 描边接近，需要在真实 1× Windows 屏幕复核；macOS Retina 截图不能替代这个步骤。

像素规则：以整数坐标为主，圆弧允许半格校正。不对 1.8 描边做“全部半像素吸附”的机械处理；在目标尺寸和系统缩放下以轮廓清楚、横竖重量相近为准。不要给 SVG 加 transform 放大、CSS stroke-width 覆写或父容器全局 svg 尺寸。

## 主题、状态与无障碍

复用 theme.ts 的矿物、石墨、陶土、记事本、灰白黑五种主题。当前主题列表全是浅色；本次没有新增深色模式或品牌色。设计板仅在自身根节点设置现有 tokens，不调用 applyTexaTheme，不写 localStorage、不调用桌面外观 IPC。

默认用 color-text-primary；次级用 color-text-secondary；hover 用既有 surface-muted；选中用 color-accent + accent-muted，并有边框/aria-pressed；禁用保留真实 disabled 与降低透明度。示例同时展示固定悬停样本和真实 hover。颜色是状态辅助手段，配合文字、边界和禁用行为。

CandidateIcon 是装饰性 SVG（aria-hidden、focusable=false），由外层按钮提供动作名称；纯图标按钮必须有 aria-label，状态按钮使用 aria-pressed，反馈用 role=status。单独导出的 SVG 是图形资产，使用方须根据装饰或信息用途补充外部名称或 title；不要把几何名称当作用户提示。

## 与产品的边界

设计板导入真实 index.css、ApprovedWorkspace.css 和主题 tokens，按钮复用 app-primary/secondary/ghost/icon-button 类；侧栏与阅读框是无 API 的展示装配，导航顺序取自 AppRail，复习未入样本，保留 BarChart3。卡片仅示范图标语境，不代表正式新增 Agent/命题入口或第二条生成链路。

未来集中入口建议按 search、textbook、textbook-retrieve、knowledge-extract、math-verify、window-restore 等稳定语义命名，再映射几何。本轮已按此语义入口接入 40 个业务文件；不卸载 Lucide，也不修改导航结构。

## 主题对比度检查

以现有 theme.ts 的十六进制 token，按 sRGB 相对亮度计算前景对 color-bg-primary 的比值（不包含透明度、hover 混色、抗锯齿）：

| 主题 | 主图形 | 次级图形 | accent |
|---|---:|---:|---:|
| 矿物 | 14.18:1 | 5.06:1 | 5.52:1 |
| 石墨 | 13.77:1 | 4.91:1 | 6.26:1 |
| 陶土 | 12.93:1 | 5.12:1 | 5.63:1 |
| 记事本 | 13.40:1 | 5.22:1 | 5.92:1 |
| 灰白黑 | 14.50:1 | 5.46:1 | 12.33:1 |

当前三类默认前景均超过 3:1 图形对比基线。选中背景、禁用、不同组件底色仍按实际组合评审；这里的 token 数值不等于整页无障碍认证。

## A 深化：当前采用的结构与比例

A 是用户选择的深化方向。最新反馈要求保留原结构、调整动作大小，而不是一概改为居中单一符号；教材检索恢复初版，知识抽取保留上一轮新版。

- 动态命题：恢复初版的 x3–16 页框与两条题干短线；加号跨度由 9 缩至 4.5 单位，中心在 (10.5, 16)，完整位于框内，不与题干相穿。
- 数学验证：保留括号与内容短线；勾选跨度缩为 5 单位，位于右下留白处，不压括号或下边界。
- 教材检索：恢复初版文档与外置放大镜的全部几何和比例，不再沿用内置镜片版。
- 知识抽取：保留新版的正文/箭头分行结构，移除外置方块；16px 去掉中间正文短线。
- 错题：完整页框内，细点排成三行（y7 / 10.5 / 14），前两行六点，末行四点后接小叉号。叉号连同原描边轮廓整体缩小 50%，以简短实心轮廓保留较轻的重量；末行下方至 y21 底框留空。

设计板 `#a-refinement` 以“初版参考 / 当前采用”展示 16/24/32px。检索两列相同是恢复初版的结果；导出和产品语境统一使用当前几何。当前 A 已接入软件，B/C 继续留在设计板。

## 正式组件接入

40 个业务文件中的已确认语义改用 Texa* 组件：导航、教材范围/管理、输入与来源按钮、练习、错题、笔记、目标、设置弹窗的关闭/编辑/删除等。窗口原生控制、加载/警告/完成状态、未设计的展开/刷新等继续保留；学科用毕业帽仍表示学科，不全局误换成错题。

数学验证标识只出现在 verify_math_result 的工具详情；普通工具详情使用受控执行标识，执行结果仍由原有状态与文字表达。随机抽题采用已确认的命题图形，不改抽题或生成行为。消息附件 📎 的历史解析不变。共享 CSS 只修正 Texa SVG 的 1.8 描边及书籍的正方形显示，旧库样式继续生效。

正式组件支持 ref、SVG 属性和可选 size，沿用按钮已有 aria-label/文字；A 抽取在正式调用点显式 size=16，确保使用减笔版。正式代码不导入设计板，不将 B/C 打包进产品。导出脚本读取正式 A 与探索 B/C 后生成静态资产。

集成验证：TypeScript/Vite 构建、40 个迁移文件及新组件的定向 lint、既有 13 条 UI/任务效果回归通过；隔离 macOS Electron 37 在学习、笔记、教材、目标四个实际组件页面检查图标与 1.8 描边，并在三尺寸检查学习输入区。教材夹具为空态，不代表真实教材数据验收；没有模型/API/用户数据库操作。未验证 Windows 安装包。

发布源码提供独立的 `frontend/icon-workspace-preview.html` 业务组件夹具；四个页面使用合成内存响应，阻止业务写请求。验收脚本不依赖本地忽略的旧预览文件。
