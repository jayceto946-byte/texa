# 已授权并启用：已提交答案的领域副作用恢复

2026-09-11：用户明确授权按本方案实现并启用。当前后端生命周期默认启动一个恢复 worker，处理与 completed/degraded outcome 原子提交的显式 effects。此前自动审批拒绝、尚未安装 worker 的描述属于 2026-09-10 的历史状态，已由本次授权和实现替代。

## 已修复的实际窗口

1. 图片题同步、流式及恢复路径均先提交答案和 effect，再执行已选择的错题导入与概念接触。领域写入失败不会把已提交答案改为失败，也不会重新生成答案。
2. task-bound graph 返回反馈提案，由 outcome 授权后执行。旧 run 或提交前中断的提案不能更新学习状态；非 task 的原有 CLI 反馈路径保留。
3. pending action 拒绝前只读检查领域收据；已经执行的操作修复为 confirmed，不能再标为 rejected。确认重试复用已有收据。

## 已实现的边界

- graph 只返回反馈提案和 UI 所需的本地概念关联；task-bound 请求不在 graph 内启动写线程。
- 对 completed/degraded 答案，在现有 `commit_outcome` 的原子 JSON 写入中同时保存经过白名单约束的 effects。没有该记录的 interrupted/stale run 不具备领域写入许可。
- 只支持两种 effect：原有图片题的可选错题导入/概念接触，以及原有 Chat 学习反馈。图片题仍必须有本次请求的 `import_to_mistakes=true`；不新增任何模型自主写权限。
- 每个 effect 使用稳定的 task/run/ordinal 操作 ID。错题插入和 learning event 使用已有唯一 ID；章节学习、SM-2、概念曝光和候选计数在各自原子存储中同时写入操作收据。收据不能随展示日志裁剪。
- 需要模型的概念修复先完成并冻结结果，再开始可重试的领域写入；模型调用不持有全局 task 锁。重试不得换一组概念后继续记账。
- 图片采用任务绑定的稳定保留路径和原子复制，避免导入时移动 pending 图片后发生崩溃，重试再也找不到原路径。保留与清理都限制在现有图片目录内，不删除教材或学习数据。
- Mistake 在本地导入得到收据后才向 UI 声称已导入；失败时答案保持已提交，领域写入显示待恢复，不能把已提交 final 改成 failed 或再次生成答案。
- 一个应用生命周期管理的 worker 只处理带新 effect 记录的已提交 outcome；不追溯生成旧 task 的副作用，不重新调用回答模型，不创建第二个答案，不为未确认的 pending action 执行写入。队列在磁盘上，线程和重试间隔有上限。
- reject 先只读检查领域操作收据；已执行的 action 不允许再标为 rejected。确认重试复用收据并修复 action 状态。

## 验收要求

- 在 outcome 提交前中断：所有领域计数及错题记录不变。
- 在每个领域写入后、effect receipt 前注入崩溃：恢复后只有一条错题/learning event，曝光、复习次数和 SM-2 只更新一次。
- 冻结概念结果后重启：不重新选择概念；任务锁不被 blocking provider 持有。
- 旧 run、重复 worker、重复恢复请求以及多个 conversation 交错：不重复写入，也不改变新 run 的 authority。
- 启动恢复不能产生新模型答案、重复 assistant message 或额外确认动作。
- 图片复制前后断电/异常：至少保留一个可读输入，重试不会产生不同的目标图片或错题 ID。
- 补齐拒绝/确认收据丢失交错、worker 关闭及失败重试测试，再运行全量后端、前端及桌面端回归。

## 运行与存储说明

- `backend/services/execution_effects.py` 使用现有 task JSON 作为持久队列；每个答案只接受一种现有反馈提案。旧 task 没有 effects 时保持只读，不补造或批量重放历史学习行为。
- worker 随后端启动默认启用，默认每 5 秒扫描；单项失败退避 5–300 秒。图片题在 outcome 提交后也会尝试一次本地落账。状态读取接口 `GET /api/chat/tasks/{task_id}` 只读，不触发领域执行。
- 章节学习、SM-2 和 ConceptMemory JSON 增加永久操作收据；错题与 learning event 复用唯一 ID。无依赖重装、SQLite schema 迁移或历史数据改写。旧版本可读原有字段，但不能承担新的恢复保证。
- 概念提取/修复结果先冻结在 effect 中；领域重试复用冻结结果。相关模型请求设置 30 秒超时且不做客户端自动重试；不会调用答案生成链路。
- 关闭时停止扫描，在各领域步骤之间检查取消。已经进入的同步存储调用允许完成；最多等待 2 秒后退出生命周期，剩余条目保留待下次启动恢复。无法强制取消不遵守超时的第三方同步 provider。
- 并发锁和原子 JSON 领域写入的保证针对 Electron 托管的单个后端进程；不支持多个独立后端同时写同一数据目录。
- 前端仅在收到成功收据后显示“已导入错题本”；待恢复时保留正文并静默刷新状态。恢复投影更新原 assistant message ID，不追加第二份答案。
