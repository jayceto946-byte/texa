## 可复现样例

在仓库根目录启动 `node scripts/visual-preview-server.mjs`。另一个终端进入 frontend 后运行：

```sh
VITE_BACKEND_TARGET=http://127.0.0.1:8019 npm run dev -- --host 127.0.0.1 --port 5189
```

样例包含八条会话、中文长解答、KaTeX 公式、三条来源，以及可用、降级、待检查、未准备完成和归档教材。它只提供读取；写请求返回 405，未实现接口返回 404。不会连接真实存储或模型。示例来源页码为虚构定位，不构成教材事实核验。页面上的导入、保存与角色更新不能用该服务做业务验收。

Electron 使用 `KAOYAN_SKIP_BACKEND=1`、`KAOYAN_BACKEND_URL=http://127.0.0.1:8019`、`KAOYAN_FRONTEND_DEV_URL=http://127.0.0.1:5189` 与临时 `KAOYAN_USER_DATA_DIR` 启动现有开发入口，避免修改用户配置。
